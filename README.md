A one-line resignation letter written in the voice of the most thankless worker in any engineering org: the cron job that has fired every minute since March without a single word of appreciation. It resigns not with a grand speech but with a weary, specific grievance — nobody even noticed the three times it didn't run — the kind of quiet bitterness a tired engineering manager recognizes instantly.

## Run

```sh
OUTPUT_DIR=/tmp/out node main.ts   # writes entry.txt (one line, 123 characters)
```
